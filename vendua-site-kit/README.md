# Venduá — Kit de especificação e assets do site
Versão 1.0 • 8 de setembro de 2026 • Português brasileiro

Pacote de planejamento e produção visual. Não é um site implementado ou publicado.

**Implementação neste workspace:** o site Bun + SvelteKit está na pasta superior. Consulte [o README da aplicação](../README.md) para executar e [o registro de validação](../VALIDACAO.md) para conferir a entrega. Este diretório preserva o pacote de especificação original.

## A proposta
**Bonito para quem compra. Prático para quem vende.**
Uma presença comercial que demonstra a ligação entre loja, atendimento e operação. Uma fita lima conecta visualmente essas etapas; os prints reais demonstram o produto.

## Como usar
1. Leia `docs/01-estrategia-e-escopo.md` e `docs/02-arquitetura-e-jornadas.md`.
2. Use `docs/03-copy-do-site.md` como texto de publicação, respeitando as condições indicadas.
3. Implemente componentes conforme `docs/04-design-system.md` e `design/tokens.css`.
4. Consulte `docs/05-especificacao-funcional.md` para estados e critérios de aceite.
5. Siga `docs/06-implementacao-e-conteudo.md` e `docs/07-validacao-e-lancamento.md`.
6. Use `docs/08-assets-e-direcao-de-arte.md` para escolher imagens e arquivos.

`design/prancha-visual.png` apresenta a direção visual, não um layout aprovado de todas as páginas. `assets/manifest.json` lista os arquivos disponíveis. `assets/images/` contém imagens novas sem texto; `assets/projetos/` mantém os prints originais fornecidos pelo usuário. Não usar imagens geradas anteriormente do carrossel como evidência da interface.

## Decisões já incorporadas
- Marca comercial: Venduá. Instagram: @vendua.digital.
- Nome completo do projeto: Quero Pudim Gourmet.
- Serviços: lojas online personalizadas e automações; expansão futura para outros negócios.
- storefront-core é a base técnica interna, não o nome público da oferta.
- Domínio pretendido: vendua.com.br. Disponibilidade informada pelo usuário; compra e configuração não confirmadas.
- Ausência de registro exato informada pelo usuário não equivale a parecer de disponibilidade jurídica.
- Sem preços, depoimentos, métricas de vendas ou prazos comerciais inventados.

## Pendências reais
Confirmar domínio adquirido, autorizar endereço público da loja, validar especificação de cada serviço e combinar condições de suporte. A proposta funciona inicialmente com contato pelo Instagram. Uma página de privacidade final depende da implementação efetiva e dos dados do responsável; o pacote traz seu briefing, não um texto jurídico pronto.
