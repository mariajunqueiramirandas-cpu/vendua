## Revisão de interface

- **Temas.** Claro (padrão): fundo `#f7f4ea`, texto `#123c32`, apoio `#4f6a5e`, acento lima `#d9f875` reservado a preenchimentos; texto de acento usa `--color-accent-ink`. Escuro (alternável, persistido em `localStorage` sob `vnd-theme`): fundo `#0a100d`, texto `#f7f4ea`, apoio `#9dafa4`, acento `#d9f875`.
- **Contraste.** Escuro: texto/fundo ≈ 17:1; apoio/fundo ≈ 8:1; lima/fundo ≈ 16:1. Claro: texto/fundo ≈ 11:1; apoio/fundo ≈ 5.9:1; verde `#123c32`/lima ≈ 7:1.
- **Alternância de tema.** Inicializada em `app.html` antes da primeira pintura (sem flash); shaders recebem o tema via uniforme `u_dark` — no modo claro os coeficientes ficam negativos para subtrair tinta sobre o papel em vez de somar luz. Palavras vazadas (`-webkit-text-stroke`) carregam contorno no contraste do texto; palavras serifadas de acento são decorativas dentro de títulos com texto sólido adjacente.
- **Motion.** GSAP 3.15 + ScrollTrigger dentro de `gsap.matchMedia` com `prefers-reduced-motion` e `min-width`; estados iniciais são aplicados apenas em runtime, então o HTML pré-renderizado permanece completo sem JS.
- **Shaders.** Utilitário compartilhado `src/lib/gl.ts`: pausa por IntersectionObserver, recuperação de contexto, quadro único sob movimento reduzido.
- **Modal.** `<dialog>` nativo: Esc, clique no backdrop e retorno de foco verificados.
- **Fontes.** Auto-hospedadas via Fontsource (Space Grotesk variável, Instrument Serif itálica); subconjuntos latinos ≈ 44 KB.
- **Grão de filme.** Sutil, via feTurbulence em overlay fixo.

## Comandos e resultados

- `bun run check`: zero erros e zero avisos do svelte-check.
- `bun run build`: HTML estático, assets e 404 gerados com sucesso.
- `bun run test:e2e`: **16 testes aprovados** — larguras, tema, ausência de JS, destino do Instagram, modal de transmissão (abre por clique e teclado, fecha por Esc/botão/backdrop, devolve o foco), acordeão de perguntas, skip link, véu de introdução, axe, zoom, links, SEO, desempenho e capturas.
- `bun run format:check`: todos os arquivos cobertos formatados.

Em viewport de 390 px, a soma das respostas iniciais foi **166.002 bytes** (HTML/CSS/JS/SVG/WOFF2 com gzip para comparação com o orçamento; fontes contadas em tamanho bruto). JavaScript: **80.712 bytes gzip** (inclui GSAP + ScrollTrigger + o shader WebGL2). Detalhamento em `artifacts/performance.json`. Medição local, sem simular latência de produção; não é resultado de Core Web Vitals nem garantia de desempenho de hospedagem.
