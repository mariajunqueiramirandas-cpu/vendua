# Instadelivery

> Role: Primary (cardápio digital) · Last researched: 2026-10-01 · Confidence: Low–medium

Importable today ([menu-import §3](../menu-import.md#3-platforms): easy).

## Distinctive features

- "Embaixadores" ambassador program on top of loyalty and cashback.
- Mandatory-or-optional scheduling for delivery and pickup.
- Print routing by sector (bar, kitchen).
- Optional display of 4+ star customer reviews and Google reviews.
- Automatic item description generation (AI).
- WhatsApp broadcasts and order confirmation; Instagram/Facebook post scheduling.

## Common to the set

Storefront, order management, PDV, QR table ordering, delivery tooling, coupons, loyalty, iFood sync and AI appear at most primary competitors. The list above is what sets Instadelivery apart.
