# Loja Integrada

> Role: Secondary (generalist storefront) · Last researched: 2026-10-01 · Confidence: Medium

Low-cost entry platform with a broad app ecosystem.

## Distinctive features

- Enviali shipping hub (Correios, Melhor Envio guides).
- Catalog distributed to Instagram, Google and TikTok.
- Meta Conversions API app; Google, TikTok and Meta Ads integrations.
- Marketplaces through its channel hub (Mercado Livre, Magalu).
- Reviews through a Trustvox app.
