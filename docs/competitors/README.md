# Competitor profiles

One file per competitor, listing what is distinctive about it and how it maps
to the gaps in [`../competitor-parity.md`](../competitor-parity.md). The set and
its roles are defined there.

Rules: every claim needs a source in the file's _Sources and caveats_ section;
`unknown` means no source was found, not that the feature is absent; no prices
or plan details without the owner's decision. Add a dated line to the file's
change log whenever you update it.
