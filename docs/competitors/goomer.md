# Goomer

> Role: Primary (cardápio digital) · Last researched: 2026-10-01 · Confidence: Low–medium (home page thin; search summaries)

Strongest on in-venue ordering.

## Distinctive features

- Tablet at the table: call waiter, close bill, rodízio mode.
- Self-service totem.
- QR code at table, counter or comanda.
- Kitchen manager: automatic printing plus KDS screen.
- Virtual attendant (chatbot) and loyalty program.
- PDV integration with partner systems (e.g. Saipos).
