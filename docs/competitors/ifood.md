# iFood

> Role: Marketplace we sell against · Last researched: 2026-10-01 · Confidence: Medium (own partner blog; some third-party)

A marketplace more than a storefront: its power is demand, not the merchant site. Direct import is blocked, planned later through the official Merchant API ([menu-import §3](../menu-import.md#3-platforms)).

## Distinctive features

- Marketplace demand and its own delivery network.
- Gestor de Pedidos app (web, Windows, mobile) with real-time order flow and delivery tracking.
- Portal do Parceiro: promotions, finance and review reports.
- PDV integration only through systems homologated on its API.
